# Duy Nguyen's Personal Website

Welcome to my personal website! This repository contains the source code for my GitHub Pages site at [duynlk.github.io](https://duynlk.github.io).

## About

This site showcases my personal projects, blog posts, photo galleries, and other content. It's built as a static website using HTML, CSS, and JavaScript.

## Structure

- `index.html` - Homepage
- `blog/` - Blog posts and articles
- `gallery/` - Photo gallery
- `wedding/` -  My Wedding
- `profile/` - About me page
- `assets/` - CSS, images, and other assets

## Technologies Used

- HTML5
- CSS3
- JavaScript
- FontAwesome icons

## Local Development

To run this site locally:

1. Clone the repository
2. Open `index.html` in your browser, or use a local server like:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`

## Deployment

This site is automatically deployed via GitHub Pages from the main branch.
